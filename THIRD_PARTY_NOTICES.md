# Dependências e componentes de terceiros

- O Gradle Wrapper incluído é o original do Gradle 8.11.1, distribuído sob Apache License 2.0. Scripts preservam seus avisos. A origem é `https://github.com/gradle/gradle/tree/v8.11.1/gradle/wrapper`. O JAR foi comparado com o SHA-256 publicado pelo Gradle; o download da distribuição possui `distributionSha256Sum` fixado.
- O CSS compilado usa Tailwind CSS 3.4.17, MIT License: `https://github.com/tailwindlabs/tailwindcss/blob/v3.4.17/LICENSE`.
- Android Gradle Plugin, Kotlin Gradle Plugin, Kotlin stdlib e seus componentes são obtidos pelo Gradle nos repositórios configurados e preservam suas respectivas licenças.
- Node.js e SQLite usam as licenças de suas distribuições e não são empacotados como executáveis neste projeto.
- `referencia/novo_Painel2.html` é a cópia preservada do arquivo fornecido pelo usuário.
